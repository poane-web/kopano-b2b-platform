# Kopano — Group Buying for Botswana SMEs

Kopano is a mobile-first B2B group buying platform that helps small businesses in Botswana pool their purchasing power to access wholesale prices.

## Quick Start

```bash
# 1. Clone and enter directory
cd kopano

# 2. Copy environment variables
cp .env.example .env
# Edit .env with your actual API keys

# 3. Start everything
docker-compose up --build

# 4. Seed database (first run only)
docker-compose exec postgres psql -U kopano -d kopano -f /docker-entrypoint-initdb.d/init.sql

# 5. Open app
# Frontend: http://localhost:5173
# API: http://localhost:3000/api
# Admin: http://localhost:5173/admin
